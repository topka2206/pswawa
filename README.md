# ps.wawa — сайт

Аренда PS5 и кальянов с доставкой по Варшаве. Статичный сайт: быстрый, без базы данных и серверного кода.

## Как устроено

| Папка | Что внутри | Кто правит |
|---|---|---|
| `content/` | цены, частые вопросы, игры, настройки и включение блоков | ты — через админку `/admin` |
| `templates/` | разметка и тексты страниц `ru/`, `uk/`, `en/`; `ui.<язык>.json` — title, description, подписи | разработчик (Claude) |
| `static/` | стили, скрипты, шрифты, картинки, админка | разработчик |
| `_src/build.py` | собирает всё в папку `dist/` — это и есть готовый сайт | запускается сам на Netlify |
| `_src/make_images.py` | перегенерирует OG-превью и фавиконки | разработчик, при смене дизайна |

## Как обновлять сайт после запуска

**Цены, вопросы, игры, блоки** — открой `https://pswawa.pl/admin`, войди через GitHub, поменяй поле, нажми «Опубликовать». Через ~1 минуту изменения на сайте. Цена меняется сразу везде: карточки, таблицы, разметка Google, справка для AI (`llms.txt`).

- Убрать анонс GTA VI или любой блок главной: **Настройки и блоки → Блоки на главной** → выключить.
- Добавить вопрос: **Частые вопросы (RU / UA / EN)** → «Добавить» → отметить страницы, где показывать. Вопросы на каждом языке ведутся отдельно.
- Цены, игры и блоки общие для всех трёх языков — меняются один раз.
- Пустое поле цены (например, «2 дня») = на сайте покажется «в Direct».

**Новые блоки, страницы, дизайн** — пиши Claude в проекте «Сайт PS.WAWA».

## Запуск (один раз)

1. Создать репозиторий на GitHub (например, `pswawa`), загрузить туда эту папку (без `dist/`).
2. Netlify → Add new site → Import from GitHub → выбрать репозиторий. Настройки сборки подтянутся из `netlify.toml`.
3. Netlify → Domain management → подключить домен.
4. Админка: GitHub → Settings → Developer settings → OAuth Apps → New (callback: `https://api.netlify.com/auth/done`). Client ID/Secret вставить в Netlify → Site configuration → Access & security → OAuth → GitHub. В `static/admin/config.yml` вписать `repo: topka2206/pswawa`.
5. В админке: Настройки → Google Analytics ID.

## Локальная сборка

```
pip install -r requirements.txt
python3 _src/build.py
cd dist && python3 -m http.server 8000   # открыть http://localhost:8000/ru/
```

## Языки

- `/ru/`, `/uk/`, `/en/` — отдельные страницы для Google (hreflang).
- Главная `/` сама открывает язык посетителя: сначала его ручной выбор, потом языки телефона по порядку (украинский → `/uk/`, русский или белорусский → `/ru/`, английский → `/en/`), иначе русский.
- Переключатель RU · UA · EN в шапке ведёт на ту же страницу на другом языке и запоминает выбор.
- В шапку Instagram ставь ссылку на корень домена — так каждый попадёт на свой язык.
